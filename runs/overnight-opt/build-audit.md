The pinned production image already had the historical 0171z fixes for those errors. The CUDA argmax kernel also calls a device function before its declaration; the historical odds build supplied the 0186z declaration. The benchmark reproduces the frozen GPU images' embedded kernels and builds both the HTTP native executable and standalone rank-one follower. The integration replay also exposed a bug in 0169. The hot-expert selector used an eight-element array indexed by the expert ID despite a vocabulary of 385 expert IDs per layer. A separate early return discarded every result when the caller requested more entries than its output buffer could fit. Both can invalidate the older hot:2 and hot:4 screens. The repair walks descending counts with a stable expert-ID tiebreak, bounded by the actual expert count and caller capacity. Its test exercises IDs 8, 128 and 384 and a truncated output. Two clean builds passed all 768 Debug host tests in 27 build steps after this repair and a test-only counter observation fix. The Linux host test declarations select Debug independently of the requested application mode. The latter makes the optimized planner mutation test actually read its two observed counters.
