### Switch semantics

`TF_DS_CONF_LEADER_ONLY=1` or `on` (model.zig `envOnOff`, the boolean-switch pattern; anything else
off; unset: the served engine, both ranks compute). The flag is the AND of four conditions
(`draft.confLeaderOnly`, pinned by test):

1. the switch is on;
2. **this rank is a follower** (`m.rank != 0` — rank 0 is the pair's Lanes leader; `lanes.follow` runs
   on ranks 1-3, which is where `.pass` frames execute);
3. **TF_DS_CHECK_INVALID is off** (the head's pack/gather kernels write `ch.invalid`, the invalid-ID
   flag — the checks are preserved when the diagnostic is enabled);
4. **TF_DS_PASS_PROFILE is off** (the profile times the head's `.conf` phase on this rank).

On a skipping follower: `body()` returns right after the Markov loop's last collective (the drafts'
`_pick` rides it; `dr.out` is fully computed), skipping the `ch.invalid` memset, the confidence
input's packing (`TF_DS_CONF_PACK`'s one `confPack` or the gatherRows/toF32/copyRows chain), the FP32
GEMV (`blas.xv`) and the scores' `cuMemcpyDtoH`. The draft-ID download (`ho` → `dr.drafts`) is kept
when a consumer needs it — `TF_DS_ENGRAM_SUBMIT_EARLY`'s stash hashing (`stashWants`) or `m.prof`'s
pass counters — and dropped otherwise. `e.s.synchronize()` stays (see Open decisions).

### The rank-role condition (documented per the gate)

- **Leader (rank 0) never skips**: its `draftFn` runs `holdDrafts` (`lanes.zig:1833`) on `d.confs` and
  prices draft depth from the scores (`probabilitiesFn` → `survivals`; `verifyFn`'s triage reads
  `l.confs` at `lanes.zig:1450`). With the switch set on rank 0 the behavior is baseline.
- **Followers (ranks 1-3) skip when the four conditions hold.** The follower's `.pass` frame handler
  (`lanes.zig:2836-2847`) consumes only `d.drafts` (the SUBMIT_EARLY stash) and never `d.confs`; the
  gate items — draft IDs, held depths (`dep = steps`, `lanes.zig:2841`; the leader's `holdDrafts`
  untouched) and stashed rows (`stashPass`'s `en.ids`/hashes) — are produced host-side from `dr.out`,
  which the skip does not touch.
- **Rank-local, not in the fingerprint**: `rank_identity.featureString` covers state/protocol switches
  only; this one changes no wire frame and no output bit (an uneven env is safe — set it on both
  ranks for hygiene; rank 0 ignores it). World 4's 2D split (ranks 1-3 all follow rank 0; the Markov
  gather is 4-way over `draft2d`) is covered by the same role condition and the conf head is purely
  local there too — argued, not exercised (served shape is world 2).

## Micro-evidence: launches/bytes removed per follower pass

Per pass at N streams × `steps` drafts (the served geometry: `hidden` 5120 + `markov_rank` 256 =
5376 fp32/row, `config.zig:263-268`):

| Removed | TF_DS_CONF_PACK=1 | chain (default) |
|---|---|---|
| GPU launches | 3 (`cuMemsetD8Async` + `confPack` + GEMV) | 2N+5 (memset + N `gatherRows` + N `toF32` + `toF32`(embs) + 2 `copyRows` + GEMV) — 7 at 1 stream, 13 at 4, 21 at 8 |
| Confidence input packed (writes to `conf_in`) | N·steps·21504 B | same |
| — at 1×6 (the item's shape) | **126 KiB** (129,024 B) | 126 KiB |
| — at 4×6 | 504 KiB | 504 KiB |
| GEMV input reads | N·steps·21504 B + 21,504 B (`confw`) | same |
| Score download (`cuMemcpyDtoH` of `dr.conf`) | N·steps·4 B (24 B at 1×6) | same |
| Draft-ID download | kept with SUBMIT_EARLY/m.prof (N·(steps+1)·8 B = 56 B at 1×6); dropped otherwise | same |

The chain additionally writes N·steps·rank·2 B (`embs`), N·steps·d·4 B (`xcf`) and N·steps·rank·4 B
(`ef`) of fp32 staging. One host round-trip (`cuMemcpyDtoH` + the `dr.confs` fill) is gone on every
skipping pass. `confWork()` computes these numbers and the first skipped pass logs them
(`draft.zig:899-903`) — that log line is the operator's runtime micro-evidence.

## Open decisions (for the operator / parent)

1. **The follower's host wait stays.** `e.s.synchronize()` in `Drafter.pass` runs even when both
   downloads are dropped (no SUBMIT_EARLY, no profile), so the follower's frame loop still waits for
   the pass body — its arrival win is the confidence tail only. Dropping the wait when nothing reads
   back is a small change with an error-attribution cost: a pass's async launch error would surface
   on a later frame's call instead of at the pass (today `roundRefused` sees it there). Operator's
   call; the stream ordering itself is safe (`m.eng.s == m.stream`, `model.zig:495`).
2. **The handoff prefetch stays on the follower.** With `TF_DS_DRAFT_PREFETCH=2` the follower still
   issues the post-Markov handoff prefetch + the body's owed join (it warms the follower's own next
   verify; dropping it is a forward-latency regression, not this item's energy win). If the operator
   wants the literal "no GPU work past the last Markov collective", move the skip above the handoff —
   one line, but recommend not.
3. **World 4 (the 2D split) is argued, not exercised.** The role condition and the conf head's
   locality carry over (ranks 1-3 all follow; the Markov gather is 4-way and untouched), but the
   served pair is world 2 and the gate above runs there.
