  1. rsyncs the README's exact two file lists to the head (the README's commands verbatim — `window.sh` itself is
     deliberately not in the synced list),

     each with the README's own launch line (topk's `tee` form, detached),
  3. gates each step on its `run.log`: the next step starts only after the log shows `restored: validate rc=0`

     `finished` line → one re-read of the log (exit race), then stop.
  4. carries the hazard notes in its header and echoes them at start: never just sync-head (the checkout's `.env`
     is three deploys stale — `just sync-head` would push it over the head's live one; only the exact file lists
     move, `.env` is never synced); production must be idle before step 1; one script at a time.

  edited (recipe proposed below). `runs/overnight-20261122/**` read-only (gate run reads saved suites only).
